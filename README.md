# 🐦 Automated Bird Monitoring using YOLO and Tracking

## 📌 Overview
This project detects, tracks, and counts birds in real-time using computer vision. It uses YOLOv8 for object detection and tracking algorithms to assign unique IDs to birds and count them when they cross a virtual line.

The system is designed for applications like **aviation safety**, **wildlife monitoring**, and **surveillance systems**.

---

## 🚀 Features
- Real-time bird detection using YOLOv8
- Object tracking with unique IDs (BoT-SORT / ByteTrack)
- Virtual line-based counting system
- Prevents duplicate counting using tracking IDs
- Works on both video files and live camera feed

---

## 🛠️ Tech Stack
- Python 3.12
- OpenCV
- Ultralytics YOLOv8
- NumPy
